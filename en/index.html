FAQ

Fair questions before installing a scraper.

Does my scraped data go through a server?

No. Scraped data is processed and stored locally in your browser. The only thing that leaves your browser is the Pro license check (email and license key), never the data you scrape.

Does it work on sites with infinite scroll?

Yes. The extension detects infinite scroll and waits for real DOM changes instead of a fixed delay picked by hand.

Can I use it on e-commerce sites and marketplaces?

Yes, especially for listings and pages that load content when you scroll or change filters. Pagination detection adapts to how each site actually loads results. Only scrape data you are allowed to, following each site's terms.

What happens if the site's HTML changes?

A health check compares match rates against a baseline. If a selector breaks, you get a warning before the run or when the job finishes.

Does it work on sites built with Web Components (Shadow DOM)?

Yes, when the Shadow DOM is open (the most common case): you pick fields inside a component with a click, same as on any other page.

Will I lose rows if the list shows two identical items?

No. If the page shows two identical items, both are exported. Only items read again while scrolling or loading more are skipped, so you don't get false duplicates.

Is it a tool for developers?

Not mainly. It's built for people who need reliable CSVs without writing CSS, XPath or scripts.

What languages is the extension available in?

English and Spanish. It follows your Chrome language automatically: the side panel, notifications, suggested column names and the checkout all switch together.
