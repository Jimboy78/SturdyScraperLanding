# Landing de Sturdy Scraper

Landing estatica para validar, publicar el producto y cumplir requisitos basicos de Paddle.

## Uso local

Abrir `index.html` directamente en el navegador.

## Publicacion

Se puede subir tal cual a GitHub Pages, Cloudflare Pages, Netlify o cualquier hosting estatico.

Antes de publicar:

- Cambiar el `canonical` por el dominio real.
- Cambiar `support@sturdyscraper.com` por el email real si el dominio final es otro.
- Cambiar el `mailto:` del formulario por el endpoint real de waitlist cuando exista.
- Verificar que los precios visibles coincidan con Paddle: Free, Pro USD 9/mes, Pro USD 79/ano.
- Publicar estas paginas junto a la home:
  - `terms.html`
  - `privacy.html`
  - `refund-policy.html`

## Links publicos que Paddle suele pedir

- Website: `/index.html`
- Terms of Service: `/terms.html`
- Privacy Policy: `/privacy.html`
- Refund Policy: `/refund-policy.html`
- Contact: `support@sturdyscraper.com` visible en home, footer y paginas legales.
